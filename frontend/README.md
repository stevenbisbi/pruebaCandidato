# Frontend

React 18 + TypeScript + Vite 6 + Tailwind 3 + Redux Toolkit (RTK Query para la API). Las rutas usan la
History API y los formatos `Intl`, sin otras librerias (DECISIONS.md, D-08). Ver el README de la raiz.

```bash
npm ci
npm run dev   # http://localhost:5173, proxy de /api a localhost:8080
npm test
```
